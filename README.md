# Coverse Cafe – Local Business Website

A responsive local business website created for **Coverse Cafe**, located at Vertex Ashoka, Bejai, Mangaluru.

This project was developed as part of the **Future Interns Full Stack Web Development Task 3 – Build, Pitch & Monetize a Real Local Business Website**.

> **NOTE:** This is a conceptual/demo website created for academic and internship purposes. It is not the official website of Coverse Cafe and does not claim any official affiliation with the business.

## About the Business

Coverse Cafe is a local café located at Vertex Ashoka, Bejai, Mangaluru.

The website presents the café’s menu, location, contact information, and enquiry options in a simple and customer-friendly format.

---

## Problem Solved

Customers may need to search across different platforms to find information such as the menu, location, contact details, and directions.

This website brings all the important information together in one place.

---

## How the Website Helps the Business

The website helps Coverse Cafe by:

- Creating a professional online presence
- Making the menu easier to explore
- Helping customers find the café through Google Maps
- Providing quick access to contact details
- Allowing customers to send enquiries
- Making the business easier to discover on mobile and desktop

---

## Key Features

- Responsive design
